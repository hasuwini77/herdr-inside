# Herdr 0.9.1 to 0.9.5, for people who drive agents all day

The official changelog lists every fix. This page keeps the changes that alter how you work, with the config or command to use them. Source: [`docs/next/CHANGELOG.md` at v0.9.5](https://github.com/herdrdev/herdr/blob/v0.9.5/docs/next/CHANGELOG.md).

Check your version first:

```bash
herdr --version
```

## Do these after updating

**Reinstall your integrations.** Several releases changed hook files, and an old install keeps the old behaviour. In 0.9.5 Herdr stopped installing Codex turn hooks and went back to screen detection for Codex.

```bash
herdr integration install claude
herdr integration install codex
```

**Restart servers that are still on the old binary.** Since 0.9.2, `herdr update` lists every running server still on the old version, with the command to restart each one. Saved SSH machines need their own update.

## Sessions survive more

- **Reboots keep your agents** (0.9.4). Herdr saves before macOS or Windows starts closing apps, so agents come back where they were.
- **Saves are crash-safe** (0.9.4). A save is written to disk before it replaces the old file.
- **48 layout snapshots** are kept in `session-snapshots/` (0.9.2). If a restore goes wrong, the previous layouts are still there.
- **Closing the launching shell no longer stops the server** (0.9.4, Linux and macOS). If a script stopped Herdr with `SIGHUP`, switch it to:

```bash
herdr server stop
```

- **Restored agents start one by one**, 100 ms apart (0.9.2). Twenty agents booting at once used to fight over CPU. Tune the gap:

```toml
[session]
startup_per_agent_delay_ms = 250
```

## Status you can trust more

- An agent's **first task counts as done**, even when it started with a prompt (0.9.2). Restores no longer fire false "done" notifications.
- **Claude Code questions show as blocked** in named sessions (0.9.5).
- **Clicking a pane no longer sends a stray Escape** (0.9.2). Before this, a click could interrupt a working agent.
- Antigravity and Grok count as **idle at their prompt** even while their own background tasks run (0.9.4).

Chapter 02 explains where these states come from: [How Herdr knows an agent is working](../chapters/02-agent-status.md).

## Agents can report themselves

Since 0.9.2 an agent can tell Herdr its own state and **resume command**. Herdr then reopens that exact session after a restart, with no built-in integration. If you build an agent or a wrapper, start with the official guide: [Add Herdr support to your agent](https://herdr.dev/docs/add-herdr-support/).

## Keys

Two prefixes at once (0.9.2):

```toml
[keys]
prefix = ["ctrl+space", "ctrl+s"]
```

Clear a pane's screen and scrollback but keep the prompt line (0.9.2, unbound by default):

```toml
[keys]
clear_pane = "prefix+k"
```

Ctrl shortcuts now work on Russian, Greek and Hebrew layouts, and Option+arrow word jumps work again in Ghostty and iTerm2 (0.9.3, 0.9.4).

## Plugins

Update every plugin installed from GitHub in one command (0.9.4). Running plugin panes keep their old files; new runs use the update, with no config reload:

```bash
herdr plugin update
```

Locally linked plugins are skipped, so your dev copy stays yours.

Sidebar token rules can **hide** tokens (0.9.1). A row with no tokens left disappears. This entry in a sidebar row hides the machine label when it is exactly `Local` (example from the [configuration docs](https://github.com/herdrdev/herdr/blob/v0.9.5/docs/next/website/src/content/docs/configuration.mdx)):

```toml
{ token = "machine", fg = "#61afef", rules = [{ equals = "Local", hide = true }] }
```

Chapter 03 covers tokens end to end: [Plugins and sidebar metadata](../chapters/03-plugins-metadata.md).

## Breaking: the pane graphics API is gone

`pane.graphics.info`, `set`, `clear` and `stream` return `unknown_method` since 0.9.2. Apps show images by writing standard Kitty graphics to the terminal, and Herdr renders them. If a script of yours called these methods, it needs that change.

## Remote machines

- Run any command against a saved SSH machine without opening a window (0.9.1):

```bash
herdr --machine my-server agent list
```

- `herdr machine status` checks saved machines without prompting, and `herdr machine reconnect` finishes SSH login, MFA included, in your terminal (0.9.2).
- SSH links use compression and send only changed rows (0.9.2). Long build logs over a slow link catch up much faster.

## On master, not released yet

Commits merged after v0.9.5, from the repository history. They can still change before a release.

- The macOS server keeps running when its terminal quits (#5236).
- A slow server keeps its socket instead of being treated as stale on a connect timeout (#5511).
- The saved layout survives panes that die during host shutdown (#5510).
- Clients that stop reading no longer get a queue of stale screens (#6097).
- Very large sessions (500+ panes) reap pane shells and retry interrupted handoff reads (#6107).
- The terminal theme stays readable on light terminals (#6092).
